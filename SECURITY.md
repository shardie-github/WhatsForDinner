# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities via GitHub Security Advisories.
Do not create public issues for security vulnerabilities.

**How to report:**
1. Go to the Security tab in this repository
2. Click "Report a vulnerability"
3. Fill out the advisory form with details

## Security Best Practices

- **No secrets in repository**: All secrets must be stored in environment variables or secret management systems
- **Rotate credentials immediately** upon suspicion of compromise
- **Responsible disclosure appreciated**: We will acknowledge receipt within 48 hours and work with you to resolve the issue

## Security Updates

- Security patches are released as soon as possible after vulnerability identification
- Critical security updates are announced via GitHub Releases
- See [SECURITY_CHECKLIST.md](./SECURITY_CHECKLIST.md) for our comprehensive security controls

## Supported Versions

We provide security updates for the latest stable release and the previous major version.

## Security Contact

For security concerns, please use GitHub Security Advisories. For general security questions, tag maintainers in Issues.
