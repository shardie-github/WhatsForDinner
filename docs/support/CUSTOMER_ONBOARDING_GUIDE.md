# Customer Onboarding Guide

**Purpose:** Ensure new users successfully activate and find value

---

## Onboarding Goals

1. **Activation:** User plans their first meal within 24 hours
2. **Engagement:** User uses app at least 3 times in first week
3. **Conversion:** Free user upgrades to Premium within 30 days

---

## Onboarding Flow

### Step 1: Welcome (Immediate)

**Email:** Welcome email sent immediately after signup

**In-App:**
- Welcome modal with quick tour
- "Get Started" button
- Skip option for experienced users

**Goal:** Set expectations and guide to first action

---

### Step 2: Profile Setup (2 minutes)

**Actions:**
- Add name and preferences
- Set dietary restrictions
- Choose cooking skill level
- Set meal preferences

**Goal:** Personalize experience

---

### Step 3: Add Pantry (3 minutes)

**Actions:**
- Add at least 5 pantry items
- Import from recipes (optional)
- Set pantry location

**Goal:** Enable meal suggestions

**Tips:**
- Show examples
- Make it easy to add multiple items
- Suggest common items

---

### Step 4: First Meal Suggestion (30 seconds)

**Actions:**
- Click "Generate Meals"
- View AI suggestions
- Select a meal
- View recipe details

**Goal:** Show value immediately

**Tips:**
- Make it one click
- Show impressive results
- Highlight AI personalization

---

### Step 5: Meal Planning (2 minutes)

**Actions:**
- Plan meals for the week
- Add to calendar
- Generate grocery list

**Goal:** Complete first meal plan

---

### Step 6: Grocery List (1 minute)

**Actions:**
- Review generated list
- Edit items
- Share or export

**Goal:** Show practical value

---

## Onboarding Emails

### Email 1: Welcome (Day 0)
- Welcome message
- Quick start guide
- Link to onboarding

### Email 2: First Meal (Day 1)
- Reminder to plan first meal
- Tips for better suggestions
- Link to meal planner

### Email 3: Features (Day 3)
- Highlight key features
- Show advanced options
- Link to feature guides

### Email 4: Success Stories (Day 7)
- User testimonials
- Time-saving examples
- Link to upgrade (if free)

### Email 5: Upgrade Nudge (Day 14)
- Premium benefits
- Special offer
- Link to pricing

---

- [ ] Grocery list generated
- [ ] App used 3+ times

### For Success Team

## Success Metrics

### Activation Metrics
- Signup to first meal: < 24 hours
- First meal completion rate: > 60%
- Onboarding completion rate: > 50%

### Engagement Metrics
- Day 1 active users: > 70%
- Day 7 active users: > 40%
- Day 30 active users: > 25%

### Conversion Metrics
- Free to Premium: > 5%
- Trial to paid: > 30%
- Annual plan adoption: > 20%

---

## Troubleshooting

### User Stuck on Signup
- Send reminder email
- Offer help via chat
- Simplify signup flow

### User Not Adding Pantry
- Send tips email
- Show examples
- Offer quick import

### User Not Planning Meals
- Send first meal reminder
- Show success stories
- Offer personalized help

---

## Personalization

### Based on Signup Source
- **Social Media:** Emphasize visual features
- **Blog:** Emphasize educational content
- **Referral:** Emphasize social features

### Based on User Type
- **Busy Professional:** Emphasize time-saving
- **Health Enthusiast:** Emphasize nutrition tracking
- **Family:** Emphasize collaboration features
