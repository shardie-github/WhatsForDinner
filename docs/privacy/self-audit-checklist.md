# Privacy Monitoring Self-Audit Checklist

Use this checklist to verify your privacy settings and ensure your data is protected.

## Initial Setup

- [ ] Read and understood the privacy policy
- [ ] Completed consent onboarding wizard
- [ ] Set up multi-factor authentication (MFA)
- [ ] Configured app allowlist
- [ ] Configured signal toggles
- [ ] Set data retention period

## Current Settings Review

- [ ] Verify monitoring is enabled/disabled as desired
- [ ] Review apps currently monitored
- [ ] Verify signal collection settings
- [ ] Check data retention period is appropriate
- [ ] Confirm MFA is enabled for sensitive actions

## Data Access & Control

- [ ] Reviewed transparency log within last 30 days
- [ ] Exported data within last 90 days (to verify completeness)
- [ ] Verified no unauthorized access in transparency log
- [ ] Checked that paused monitoring is working if applicable

## Security

- [ ] MFA is enabled and working
- [ ] Password is strong and unique
- [ ] Backup codes are stored securely
- [ ] Verified no suspicious activity in transparency log

## Data Retention

- [ ] Confirmed retention period is appropriate for your needs
- [ ] Verified old data is being deleted per retention policy
- [ ] Exported any data you want to keep before deletion

## Compliance

- [ ] Read latest privacy policy updates
- [ ] Understood your rights (export, delete, restrict)
- [ ] Know how to contact support for privacy questions
- [ ] Verified no staff/admin access to your telemetry (should be zero)

## If You Want to Disable Monitoring

1. [ ] Export your data (if you want to keep it)
2. [ ] Navigate to Privacy Settings
3. [ ] Disable monitoring
4. [ ] Verify in transparency log that consent was revoked
5. [ ] Confirm no new telemetry events are being created

## If You Suspect Unauthorized Access

1. [ ] Check transparency log for suspicious entries
2. [ ] Verify all actions in log are your own
3. [ ] Change password and rotate MFA
4. [ ] Contact support immediately
5. [ ] Consider temporarily disabling monitoring

## Regular Maintenance (Monthly)

- [ ] Review transparency log
- [ ] Update app allowlist if needed
- [ ] Adjust signal toggles if preferences changed
- [ ] Review and update data retention period
- [ ] Export data backup (optional)

## Regular Maintenance (Quarterly)

- [ ] Full privacy audit using this checklist
- [ ] Review privacy policy for updates
- [ ] Verify compliance with regulations
- [ ] Test export/delete functionality
- [ ] Update MFA backup codes if needed

## Notes

- Keep this checklist updated with dates of completion
- Store exported data backups securely
- Contact support if you have questions or concerns
- Remember: Your data is visible only to you
