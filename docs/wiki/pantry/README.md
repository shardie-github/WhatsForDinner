# Pantry Management Guide

Master your pantry with smart features that help you reduce waste, save money, and discover new recipes.

---

## 🥫 Adding Ingredients

### Manual Entry

**Quick Add**
1. Go to "Pantry" in the menu
2. Click "Add Item" button
3. Type ingredient name
4. Set quantity (optional)
5. Add expiration date (optional)

### Barcode Scanning

**Scan Items**
1. Click the camera icon
2. Scan product barcode
3. Item automatically added
4. Update quantity if needed

### Bulk Import

**Import from Receipts**
1. Take photo of receipt
2. AI extracts items
3. Review and confirm
4. Items added to pantry

## 🍳 "What's in my fridge?" Feature

### Using the Feature

**Quick Recipe Suggestions**
1. Go to "Pantry" → "What's in my fridge?"
2. Select ingredients you have
3. AI suggests recipes
4. Cook with what you have

**Benefits:**
- Reduce food waste
- Use leftovers creatively
- Discover new recipes
- Save money

### How It Works

1. **Select Ingredients**
   - Tap ingredients you have
   - Can select multiple items
   - See recipe count update

2. **Get Suggestions**
   - AI finds matching recipes
   - Shows recipes you can make now
   - Sorted by relevance

3. **Cook & Rate**
   - Try the recipe
   - Rate it (thumbs up/down)
   - AI learns your preferences

## ❓ Common Questions

**Q: Do I need to add everything?**  
A: No! Start with common items. The app learns over time.

**Q: Can I scan items without barcodes?**  
A: Yes! Use manual entry or take a photo.

**Q: How accurate are expiration alerts?**  
A: Very accurate if you set expiration dates. Enable notifications for best results.

**Q: Can I export my pantry list?**  
A: Yes! Go to Settings → Export Data.
