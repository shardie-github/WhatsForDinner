# Quick Start - Monetization in 60 Seconds

## 🚀 Enable All Channels (One Command)

```bash
# 1. Run migrations
pnpm db:migrate:monetization

# 2. Enable channels
pnpm monetization:enable

# 3. Done! Revenue flows automatically
```
