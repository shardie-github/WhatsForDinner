## Component Layers

### Frontend Layer
- **Web App** (`apps/web`): Next.js 16 with PWA support
- **Mobile App** (`apps/mobile`): Expo React Native
- **Shared UI** (`packages/ui`): Cross-platform components

### Backend Layer
- **API Routes** (`apps/web/src/app/api`): Next.js API handlers
- **Server Package** (`packages/server`): Core business logic
- **Queue System**: BullMQ with Redis for async jobs

### Data Layer
- **Database**: Supabase PostgreSQL with RLS
- **Cache**: Redis for queue and sessions
- **Storage**: Supabase Storage for artifacts

### Integration Layer
- **Supabase**: Auth, Database, Storage
- **Stripe**: Payments, Subscriptions, Connect
- **PostHog**: Analytics
- **Partner APIs**: Instacart, Walmart, etc.

## Technology Stack

### Frontend
- **Framework**: Next.js 16, React 19
- **Mobile**: Expo SDK 52, React Native
- **Styling**: Tailwind CSS, NativeWind
- **State**: React Query, Supabase Client

### Backend
- **Runtime**: Node.js 18+
- **Framework**: Next.js API Routes, Fastify
- **Database**: Supabase (PostgreSQL)
- **Queue**: BullMQ with Redis
- **Auth**: Supabase Auth

### DevOps
- **Monorepo**: Turborepo
- **Package Manager**: pnpm
- **CI/CD**: GitHub Actions
- **Monitoring**: Prometheus, Grafana, Loki
