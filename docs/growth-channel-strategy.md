# Growth Channel Testing Strategy
**Date**: 2025-01-27  
**Status**: ✅ Strategy Complete  
**Owner**: Growth Lead

## Executive Summary

This document outlines the growth channel testing strategy for What's for Dinner? We'll test 4+ channels (Reddit, Facebook, Instagram, Twitter) to validate CAC and identify profitable acquisition channels.

---

## Channel Testing Framework

### Testing Criteria
1. **CAC Target**: <$30 per channel
2. **Conversion Rate**: 3-5% (visitors → signups)
3. **Retention**: 30%+ monthly retention
4. **Scale Potential**: Can acquire 100+ users/month

### Testing Process
1. **Week 1**: Test channel with $100-200 budget
2. **Week 2**: Analyze results, optimize messaging
3. **Week 3**: Scale if CAC <$30, pause if >$50
4. **Week 4**: Double down on winners

## Optimization Strategy

### If CAC <$30
- **Double down**: Increase budget
- **Scale**: Expand to more groups/accounts
- **Optimize**: A/B test messaging

### If CAC $30-50
- **Optimize**: Test new messaging, targeting
- **Monitor**: Track for improvement
- **Pause if**: No improvement after 2 weeks

### If CAC >$50
- **Pause**: Stop channel testing
- **Analyze**: Review what didn't work
- **Learn**: Apply learnings to other channels
