# Store Readiness Checklist

## App Store (iOS)

### Required Assets
- [ ] App icon (1024x1024)
- [ ] Screenshots (6.5", 5.5" displays)
- [ ] App preview video (optional)
- [ ] Privacy policy URL
- [ ] Terms of service URL

### App Store Listing
- [ ] App name: "Nomad"
- [ ] Subtitle: "Meal Planner & Health Tracker"
- [ ] Description (4000 chars max)
- [ ] Keywords (100 chars max)
- [ ] Support URL
- [ ] Marketing URL (optional)

### Privacy & Compliance
- [ ] Privacy policy (required)
- [ ] App Privacy details (data collection)
- [ ] Age rating (4+ recommended)
- [ ] HealthKit usage description
- [ ] Location usage (if applicable)

### Technical Requirements
- [ ] Bundle identifier: `com.nomad.app`
- [ ] Version number
- [ ] Build number
- [ ] App Store Connect setup
- [ ] TestFlight beta testing

## Play Store (Android)

### Required Assets
- [ ] App icon (512x512)
- [ ] Feature graphic (1024x500)
- [ ] Screenshots (phone, tablet)
- [ ] App preview video (optional)

### Play Store Listing
- [ ] App name: "Nomad"
- [ ] Short description (80 chars)
- [ ] Full description (4000 chars)
- [ ] Privacy policy URL
- [ ] Content rating (PEGI/ESRB)

### Privacy & Compliance
- [ ] Privacy policy (required)
- [ ] Data safety form completed
- [ ] Permissions declared
- [ ] User data collected disclosed

### Technical Requirements
- [ ] Package name: `com.nomad.app`
- [ ] Version code
- [ ] Version name
- [ ] Signing key configured
- [ ] Google Play Console setup
- [ ] Internal testing track

## General Requirements

### Privacy Policy Template
Must include:
- Data collected
- How data is used
- Third-party services
- User rights (GDPR/CCPA)
- Contact information

### Terms of Service
Must include:
- User responsibilities
- Service limitations
- Content ownership
- Dispute resolution

### Consent Flows
- [ ] Onboarding consent screen
- [ ] Privacy settings in app
- [ ] Revocable consent mechanism
- [ ] CMP for web (if applicable)

### Testing
- [ ] TestFlight/Internal testing setup
- [ ] Beta tester feedback collected
- [ ] Critical bugs fixed
- [ ] Performance validated

### Marketing
- [ ] App Store Optimization (ASO)
- [ ] Screenshot strategy
- [ ] App preview video script
- [ ] Press kit prepared
