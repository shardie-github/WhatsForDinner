## Hypothesis Testing Process

### Pre-Test
1. State hypothesis clearly
2. Define success metrics
3. Plan experiment
4. Set timeline

### During Test
1. Run experiment
2. Monitor metrics
3. Ensure sample size (n > 100)

### Post-Test
1. Calculate results
2. Update status
3. Document learnings
4. Decide next steps
