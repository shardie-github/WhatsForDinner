## JTBD 1: "I need dinner ideas in under 5 minutes"

### Current Flow
1. User opens app
2. User scans pantry (or app already knows)
3. User gets 3 recipes in 30 seconds
4. User picks one
5. User cooks

### Gaps
- **Missing**: Quick-add common ingredients (friction)
- **Missing**: One-click recipe generation (could be faster)
- **Missing**: "Quick ideas" mode (faster flow)

### Success Metrics
- **Time to first recipe**: < 30 seconds (target)
- **Activation rate**: 40%+ (signups → first recipe)

## JTBD 2: "I want to use ingredients I already have"

### Current Flow
1. User adds pantry (barcode scan, manual entry)
2. App tracks pantry items
3. App generates recipes using pantry items
4. User cooks recipe
5. App updates pantry (items used)

### Gaps
- **Missing**: Receipt import (friction reduction)
- **Missing**: Expiration alerts (waste reduction)
- **Missing**: Pantry suggestions (optimization)

### Success Metrics
- **Pantry setup completion**: 70%+ (target)
- **Pantry usage**: 80%+ (recipes use pantry items)

---

## JTBD 3: "I need recipes my whole family will eat"

### Current Flow
1. User sets dietary preferences (allergies, restrictions)
2. User sets family preferences (likes, dislikes)
3. App generates recipes matching preferences
4. User rates recipes (thumbs up/down)
5. App learns preferences over time

### Gaps
- **Missing**: Family member profiles (individual preferences)
- **Missing**: Recipe filtering by family member (optimization)
- **Missing**: Family feedback (collaboration)

### Success Metrics
- **Recipe success rate: 60%+ (users cook the recipe)
