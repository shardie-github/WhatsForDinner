# Full Lifecycle Use Case: What's for Dinner

**Purpose**: Document end-to-end user journey (discover → buy → use → get value → ongoing use)  
**Last Updated**: 2025-01-27

---

## User Journey: Busy Parent (Sarah)

### Step 1: Discover
**Channel**: Google search "what to make with chicken and rice"  
**Touchpoint**: SEO landing page (`/recipes/what-to-make-with/chicken-rice`)  
**Action**: User finds recipe suggestions, clicks "Get more recipes" CTA  
**Time**: 30 seconds  
**Goal**: Get user to sign up

**Success Metric**: 10%+ signup rate (visitors → signups)

---

### Step 2: Sign Up
**Channel**: Landing page CTA  
**Touchpoint**: Signup page (`/auth`)  
**Action**: User signs up with email/social login  
**Time**: 30 seconds  
**Goal**: Get user into product

**Success Metric**: 100% completion rate (no drop-off)

---

### Step 3: Onboard
**Channel**: In-app onboarding  
**Touchpoint**: Onboarding flow (`/onboarding`)  
**Action**: User adds pantry (scans 3 items), sets dietary preferences  
**Time**: 2 minutes  
**Goal**: Create initial value, hit "aha moment"

**Success Metric**: 70%+ completion rate (pantry setup)

---

### Step 4: Generate First Recipe
**Channel**: In-app  
**Touchpoint**: Recipe generation (`/recipes/generate`)  
**Action**: User generates first recipe using pantry items  
**Time**: 30 seconds  
**Goal**: Hit "aha moment" (user realizes value)

**Success Metric**: 40%+ activation rate (signups → first recipe within 7 days)

---

### Step 5: Cook & Rate
**Channel**: In-app  
**Touchpoint**: Recipe page (`/recipes/[id]`)  
**Action**: User cooks recipe, rates it (thumbs up/down)  
**Time**: 30 minutes (cooking) + 10 seconds (rating)  
**Goal**: Create engagement loop, improve AI

**Success Metric**: 60%+ recipe success rate (users cook the recipe)

---

### Step 6: Upgrade to Pro
**Channel**: In-app upgrade prompt  
**Touchpoint**: Upgrade prompt (hits 10 recipe limit)  
**Action**: User upgrades to Pro ($9.99/month)  
**Time**: 1 minute  
**Goal**: Convert free user to paid

**Success Metric**: 5%+ conversion rate (free → paid)

---

### Step 7: Ongoing Use
**Channel**: Daily app usage  
**Touchpoint**: App (`/`)  
**Action**: User returns daily, generates recipes, app learns preferences  
**Time**: 2 minutes per day  
**Goal**: Create habit, improve recommendations

**Success Metric**: 40%+ 7-day retention, 25%+ 30-day retention

## Friction Points & Solutions

### Friction 1: Signup Friction
**Problem**: Users don't want to sign up  
**Solution**: Free tier, quick signup (email/social), value-first messaging

### Friction 2: Onboarding Friction
**Problem**: Users don't complete pantry setup  
**Solution**: Quick start (3 items), barcode scanning, tutorial

### Friction 3: Activation Friction
**Problem**: Users don't generate first recipe  
**Solution**: Email sequences, onboarding prompts, quick start

### Friction 4: Conversion Friction
**Problem**: Users don't upgrade to paid  
**Solution**: Upgrade prompts, usage-based triggers, value messaging

### Friction 5: Retention Friction
**Problem**: Users don't return  
**Solution**: Email reminders, push notifications, family sharing
